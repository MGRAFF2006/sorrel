Public guides are mirrored on the landing site under `/docs/`
(`sorrel-web/docs`). Run `npm run sync:docs` after editing a mirrored source;
`npm run validate:docs` guards the mirrors and local links.

Project progress is tracked through immutable GitHub releases and the root and
package changelogs. Do not add parallel progress dashboards, agent task packs,
or feature-audit ledgers.
